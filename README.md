# JF Go lab (6 Oct 2026)

An interactive test bench for JF Go, the staff pilot inside JF Coach. The real JF Go screen and the real
server rules run in the browser on a throwaway database with one synthetic player; GPS, compass, camera,
Health steps and the clock are levers. Nothing here talks to JF Coach's servers or touches anyone's data.
